```python
Num = 1024
CurNum = Num
for i in range(2,Num):
    count = 0
    while True:
        if CurNum % i == 0:
            count = count +1
            CurNum = CurNum/i
        else:
            break
    if count != 0:
        print(i,count,sep="")
```
