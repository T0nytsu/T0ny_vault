### T001

> [!question] T001・Core D1
> A single Python statement can require many machine instructions to execute.

> [!solution]- 解答
> **T**。一行 Python statement 先被編譯成 bytecode，再由 interpreter（本身是 machine code）執行；一個 bytecode 指令就要 CPU 跑很多條 machine instructions，例如 `print(x)` 要查名字、轉字串、輸出。

### T002

> [!question] T002・Core D1
> Ordinary DRAM keeps the running program's data after the computer loses power.

> [!solution]- 解答
> **F**。DRAM 是揮發性（volatile）記憶體，斷電資料就消失；要留下來必須存到 SSD／HDD 這類 nonvolatile storage。

### T003

> [!question] T003・Core D2
> A byte contains eight bits.

> [!solution]- 解答
> **T**。1 byte = 8 bits，可以有 $2^{8} = 256$ 種 pattern。

### T004

> [!question] T004・Core D2
> The bit pattern 10000000 has the same numeric meaning under unsigned 8-bit and signed 8-bit two's complement interpretations.

> [!solution]- 解答
> **F**。同一個 pattern 意義取決於 interpretation：unsigned 是 128，8-bit two's complement 是 $128 - 256 = -128$。

### T005

> [!question] T005・Core D2
> The largest unsigned integer representable using exactly eight bits is 255.

> [!solution]- 解答
> **T**。`11111111` = $2^{8} - 1 = 255$；範圍是 0 到 255。

### T006

> [!question] T006・Core D2
> An 8-bit two's complement integer can represent every integer from -128 through 128.

> [!solution]- 解答
> **F**。範圍是 −128 到 **127**（$-2^{7}$ 到 $2^{7} - 1$）；128 放不進去，只有 256 個 pattern，0 用掉一個正數的位置。

### T007

> [!question] T007・Core D1
> In the course's CPython model, source code can be compiled into bytecode before the runtime executes it.

> [!solution]- 解答
> **T**。CPython 先把 `.py` 編譯成 bytecode，再由 Python virtual machine（interpreter 的執行部分）逐條執行。

### T008

> [!question] T008・Core D1
> An IDE's syntax checker can determine whether every valid Python program solves its intended real-world problem correctly.

> [!solution]- 解答
> **F**。syntax checker 只檢查文法；logic error（例如華氏換算把 32 寫成 30）語法完全正確，只能靠獨立算出的預期結果去測試發現。

### T009

> [!question] T009・Core D1
> After a normal local Git commit, the new commit is automatically present on GitHub even if no push or publication occurs.

> [!solution]- 解答
> **F**。commit 只記錄在本機 repository；要 **push** 才會上傳到 GitHub。

### T010

> [!question] T010・Core D1/D2
> For a temperature converter, calculating an expected result by hand before running the candidate program provides an independent test reference.

> [!solution]- 解答
> **T**。手算（例如 10 °C → $10 \times 9/5 + 32 = 50$ °F）不依賴被測程式，所以能拿來判斷程式輸出對不對。

### T011

> [!question] T011・Core D4
> CPU caches can reduce the need to fetch some repeatedly used data from RAM.

> [!solution]- 解答
> **T**。cache 小而快、靠近 CPU，常被重複使用的資料（locality）放在 cache，就不必每次都去比較慢的 RAM 拿。

### T012

> [!question] T012・Core D4
> A higher CPU clock frequency alone guarantees faster completion of every Python program.

> [!solution]- 解答
> **F**。效能還取決於每個 cycle 完成多少指令、cache、記憶體速度、I/O（例如等使用者 `input()`）等；只看時脈不能保證每個程式都更快。

### T013

> [!question] T013・Core D1/D2
> A successful call to input() returns text even when the user types only digits.

> [!solution]- 解答
> **T**。`input()` 一律回傳 `str`，輸入 `42` 得到的是 `"42"`；要數字得自己 `int()`／`float()`。

### T014

> [!question] T014・Core D2
> int("3.5") returns the integer 3.

> [!solution]- 解答
> **F**。`int("3.5")` 會丟出 `ValueError`（字串不是整數格式）；它不會自動截斷。`int(3.5)`（對 float）才是 3。

### T015

> [!question] T015・Core D2
> Converting the identifier "007" to int preserves its leading zeros for later display with ordinary print().

> [!solution]- 解答
> **F**。`int("007")` 是 7，`print()` 印出 `7`，前導零消失。識別碼應該保留成 `str`。

### T016

> [!question] T016・Core D2
> After a = 5; b = a; a = 8, the value referred to by b is still 5.

> [!solution]- 解答
> **T**。`b = a` 讓 b 指向當時的值 5；之後 `a = 8` 只是讓 a 改指向 8，b 不受影響。

### T017

> [!question] T017・Core D2
> Starting with total = 10, executing total += 2.5 makes total equal to 12.5.

> [!solution]- 解答
> **T**。`10 + 2.5` = `12.5`（int + float 得 float）。

### T018

> [!question] T018・Core D2
> In Python 3, the expression 6 / 3 produces a float value.

> [!solution]- 解答
> **T**。`/` 永遠是真除法，`6 / 3` 是 `2.0`。

### T019

> [!question] T019・Core D2
> For positive integers, / and // always produce results of the same type.

> [!solution]- 解答
> **F**。反例：`6 / 3` 是 `2.0`（float），`6 // 3` 是 `2`（int）。

### T020

> [!question] T020・Core D2/D3
> The Python expression 2 ^ 3 computes two raised to the third power.

> [!solution]- 解答
> **F**。`^` 是 bitwise XOR：`2 ^ 3` = `0b10 ^ 0b11` = 1。次方要寫 `2 ** 3` = 8。

### T021

> [!question] T021・Core D2
> The expression 2 + 3 * 4 evaluates to 14.

> [!solution]- 解答
> **T**。乘法優先：$3 \times 4 = 12$，再加 2 得 14。

### T022

> [!question] T022・Core D2
> Dividing a distance measured in kilometers by a duration measured in minutes directly gives a speed in kilometers per hour.

> [!solution]- 解答
> **F**。km ÷ min 得到的是 km/min；要先換成小時：`speed = km / (minutes / 60)`。例：9 km、45 min，9/45 = 0.2，但正確是 12 km/h。

### T023

> [!question] T023・Core D2
> If speed = 12.345, the expression f"{speed:.2f}" produces a string.

> [!solution]- 解答
> **T**。f-string 的結果是 `str`（這裡是 `'12.35'`），不是 float。

### T024

> [!question] T024・Core D2
> Python's ordinary int values are restricted to the range of an 8-bit signed integer.

> [!solution]- 解答
> **F**。Python 的 `int` 是任意精度，大小只受記憶體限制，例如 `127 + 1` 是 128、`2 ** 100` 也能算。

### T025

> [!question] T025・Core D2
> Formatting a float to two decimal places does not by itself change the float stored in the original variable.

> [!solution]- 解答
> **T**。格式化產生一個新的字串，變數裡的 float 不變；只有重新指派才會改變它。

### T026

> [!question] T026・Core D3
> The condition duration_min >= 30 is True when duration_min is exactly 30.

> [!solution]- 解答
> **T**。`>=` 包含相等，`30 >= 30` 是 True。

### T027

> [!question] T027・Core D3
> When a and b are Boolean values, a and b is True whenever at least one of them is True.

> [!solution]- 解答
> **F**。那是 `or` 的定義；`a and b` 要**兩個都是** True 才是 True。反例：`True and False` 是 False。

### T028

> [!question] T028・Core D3
> For finite distance_km and integer duration_min, distance_km < 0 or duration_min <= 0 detects a negative distance or a nonpositive duration.

> [!solution]- 解答
> **T**。任一個條件成立就是 True，正好對應「距離為負**或**時間非正」。

### T029

> [!question] T029・Core D3
> For a Boolean value flag, ~flag is the same logical-negation operation as not flag.

> [!solution]- 解答
> **F**。`~` 是 bitwise invert，把 bool 當整數：`~True` 是 −2、`~False` 是 −1，兩個都是 truthy。邏輯否定要用 `not flag`。

### T030

> [!question] T030・Core D3
> In one if / elif / else chain, once an if or elif condition is True, later branches in that chain are skipped.

> [!solution]- 解答
> **T**。同一條 chain 只執行第一個成立的分支，其餘跳過。

### T031

> [!question] T031・Core D3
> Two separate if statements can never both execute their bodies during one pass through a program.

> [!solution]- 解答
> **F**。兩個獨立的 `if` 各自判斷。反例：`minutes = 20` 時 `if minutes <= 30:` 和 `if minutes <= 60:` 兩個 body 都會執行。

### T032

> [!question] T032・Core D3
> After time_ok = duration_min > 0, changing duration_min automatically recomputes time_ok.

> [!solution]- 解答
> **F**。`time_ok` 存的是當時算好的 bool，不是公式；duration_min 改了要自己重新算一次。

### T033

> [!question] T033・Core D3
> With duration_min = 0, the condition duration_min > 0 and 60 / duration_min > 2 avoids division by zero.

> [!solution]- 解答
> **T**。short-circuit：左邊 `0 > 0` 是 False，`and` 直接得 False，右邊的除法根本不會執行。

### T034

> [!question] T034・Core D3
> If float(distance_text) succeeds, the resulting distance must satisfy a finite-distance requirement.

> [!solution]- 解答

### T035

> A while loop checks its condition before each execution of its body.

> [!solution]- 解答

> [!solution]- 解答
> **F**。那是 `break`。`continue` 只跳過**這一輪**剩下的部分，回到迴圈開頭進行下一輪（for 取下一個值，while 重新檢查條件）。

### T041

### T061

> [!question] T061・Core D4
> Repeatedly reading the same abstract memory address, as in 100, 100, 100, illustrates temporal locality even if no neighboring addresses are accessed.

> [!solution]- 解答
> **T**。temporal locality 是「最近用過的位址很快會再用」；spatial locality 才是存取相鄰位址。

### T062

> [!question] T062・Core D3
> With `valid = False` and `minutes = 60`, the expression `valid and minutes <= 30 or minutes == 60` evaluates to `True`.

> [!solution]- 解答
> **T**。`and` 比 `or` 先算：`(False and ...)` 是 False，`False or (60 == 60)` 是 True。

### T063

> [!question] T063・Core D3

Assume n is already valid; use integer arithmetic, a loop, and no logarithm or imported module. Explain why the candidate fails for n=31 and why testing only n=32 would hide the failure. Repair it. Give expected pairs for n=1, 2, 31, 32, and 33. State an invariant, a stopping argument that establishes maximality, and a termination argument. For n=2**k with integer k >= 0, how many loop-body executions does the repaired version perform?
>
> ```python
> n = 31
> p = 1
> exponent = 0
> while p < n:
>     p *= 2
>     exponent += 1
> print(p, exponent)
> ```

> [!solution]- 解答
> candidate 對 n = 31 印出 `32 5`：`while p < n` 會一直乘到 p ≥ n 才停，所以 n 不是 2 的冪時 p 會**超過** n（32 > 31），答案應該是 16。n = 32 時 p 剛好停在 32 = n，答案碰巧正確，只測 32 會看不出錯。
>
> 修正：先確認「再乘一次仍 ≤ n」才乘。
> ```python
> n = 31
> p = 1
> exponent = 0
> while p * 2 <= n:
>     p *= 2
>     exponent += 1
> print(p, exponent)
> ```
> | n | (p, exponent) |
> | --- | --- |
> | 1 | (1, 0) |
> | 2 | (2, 1) |
> | 31 | (16, 4) |
> | 32 | (32, 5) |
> | 33 | (32, 5) |
>
> （Claude 執行，五個都相符）
> - **Invariant**：每次檢查條件時 `p == 2**exponent` 且 `p <= n`（一開始 p = 1 ≤ n；只有在 `2p <= n` 時才把 p 變成 2p）。
> - **停止時的最大性**：迴圈停下時 `2p > n`，加上 invariant 得 $p \le n < 2p$，下一個 2 的冪 2p 已經超過 n，所以 p 是最大的。
> - **終止**：p 是正整數、每輪翻倍嚴格遞增，又一直 ≤ n，有上界，所以有限次後 `2p > n`。
> - n = $2^{k}$ 時，p 從 $2^{0}$ 翻倍到 $2^{k}$，body 執行 **k** 次（例：n = 32 跑 5 次、n = 1 跑 0 次）。
