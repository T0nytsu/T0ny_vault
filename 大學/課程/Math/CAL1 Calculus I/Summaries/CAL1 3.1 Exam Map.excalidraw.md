Absolute (global) max / min value  (p. 210)
c in the domain D of f:
f(c) abs max  ⟺  f(c) ≥ f(x) for all x in D
f(c) abs min  ⟺  f(c) ≤ f(x) for all x in D
extreme values = the max and min values of f ^pUQqYErJ

Local max / min value  (p. 210)
f(c) local max  ⟺  f(c) ≥ f(x) when x is near c
f(c) local min  ⟺  f(c) ≤ f(x) when x is near c
near c = on some open interval containing c
⇒ never at an endpoint of the domain ^zJbIVUBf
