### ST 2.5.61

### ST 2.5.63
If $F(x) = f(g(x))$, where $f(-2) = 8$, $f'(-2) = 4$, $f'(5) = 3$, $g(5) = -2$, and $g'(5) = 6$, find $F'(5)$.

### ST 2.5.65
A table of values for $f$, $g$, $f'$, and $g'$ is given.

| $x$ | $f(x)$ | $g(x)$ | $f'(x)$ | $g'(x)$ |
| :---: | :---: | :---: | :---: | :---: |
| $1$ | $3$ | $2$ | $4$ | $6$ |
| $2$ | $1$ | $8$ | $5$ | $7$ |
| $3$ | $7$ | $2$ | $7$ | $9$ |

- (a) If $h(x) = f(g(x))$, find $h'(1)$.
- (b) If $H(x) = g(f(x))$, find $H'(1)$.

### ST 2.5.67
If $f$ and $g$ are the functions whose graphs are shown, let $u(x) = f(g(x))$, $v(x) = g(f(x))$, and $w(x) = g(g(x))$. Find each derivative, if it exists. If it does not exist, explain why.
- (a) $u'(1)$
- (b) $v'(1)$
- (c) $w'(1)$

### ST 2.5.70
Suppose $f$ is differentiable on $\mathbb{R}$ and $\alpha$ is a real number. Let $F(x) = f(x^{\alpha})$ and $G(x) = [f(x)]^{\alpha}$. Find expressions for (a) $F'(x)$ and (b) $G'(x)$.

### ST 2.5.73
If $F(x) = f(3f(4f(x)))$, where $f(0) = 0$ and $f'(0) = 2$, find $F'(0)$.

### ST 2.5.75
**75–76** Find the given derivative by finding the first few derivatives and observing the pattern that occurs.
$$
D^{103}\cos 2x
$$

### ST 2.5.83
Use the Chain Rule to prove the following.
- (a) The derivative of an even function is an odd function.
- (b) The derivative of an odd function is an even function.
