# Prove lim(x→3) x² = 9

## 0. 要證明什麼（ε–δ 定義）

```text
∀ ε > 0 , ∃ δ > 0   s.t.   0 < |x − 3| < δ   ⇒   |x² − 9| < ε
```

- **Preliminary analysis（草稿）**：從目標 |x² − 9| < ε 倒推回 |x − 3| < δ，找出 δ
- **`<pf>`（正式證明）**：反過來從 |x − 3| < δ 順推到 |x² − 9| < ε

---

## 1. Preliminary analysis — Find δ

### 1-1 把 |x² − 9| 拆出 |x − 3|

```text
Suppose  0 < |x − 3| < δ

|x² − 9| = |x + 3| |x − 3|
```

### 1-2 卡關：不能直接令 δ = ε / |x + 3|

```text
|x + 3| |x − 3| < ε
⇒ |x − 3| < ε / |x + 3|
```

ε / |x + 3| 含有 x，不是常數。δ 只能由 ε 決定，不能含 x。

> Because it contains x, it is not a given constant.

### 1-3 關鍵：要找 |x + 3| 的「上界」常數 C

**(i) 找下界 C < |x + 3|　✗**

```text
C < |x + 3|
⇒  C |x − 3| < |x + 3| |x − 3|
```

就算讓 C|x − 3| ≤ ε，也只知道「比 |x + 3||x − 3| 小的東西」≤ ε，管不到 |x + 3||x − 3| 本身。

> Make C become useless.

**(ii) 找上界 |x + 3| < C　✓**

```text
|x + 3| < C
⇒  |x + 3| |x − 3| < C |x − 3| ≤ ε
⇒  |x − 3| ≤ ε / C
```

ε / C 只跟 ε 有關，可以拿來當 δ。

### 1-4 先限制 |x − 3| < 1，找出 C

```text
Assume  |x − 3| < 1
    ⇒  −1 < x − 3 < 1
    ⇒   2 < x < 4
    ⇒   5 < x + 3 < 7
    ⇒   5 < |x + 3| < 7        →  取 C = 7
```

只用得到上界 7；下界 5 不影響。

### 1-5 決定 δ

```text
|x + 3| |x − 3| < |x + 3| · δ < 7 · δ ≤ ε
                            ⇒ δ ≤ ε/7
```

δ 必須同時滿足兩個條件：

```text
|x − 3| < 1        （保證 |x + 3| < 7 成立）
|x − 3| < ε/7      （保證乘積 < ε）
```

兩個都要成立 → 取較小者：

```text
δ = min{ 1 , ε/7 }
```

### 1-6 另解：改成限制 |x − 3| < 2

```text
Assume  |x − 3| < 2
    ⇒  −2 < x − 3 < 2
    ⇒   1 < x < 5
    ⇒   4 < x + 3 < 8
    ⇒   4 < |x + 3| < 8        →  取 C = 8

|x + 3| |x − 3| < |x + 3| · δ < 8 · δ ≤ ε
                            ⇒ δ ≤ ε/8

δ = min{ 2 , ε/8 }
```

兩種都對：δ 的取法不唯一，一開始的限制（1 或 2）只是為了方便找出 C。

## 2. `<pf>`

```text
Given any ε > 0, we take
    δ = min{ 1 , ε/7 } > 0    ⇒    δ ≤ 1  and  δ ≤ ε/7

If 0 < |x − 3| < δ
    ⇒  |x − 3| < 1                  (∵ δ ≤ 1)
    ⇒  −1 < x − 3 < 1
    ⇒   5 < x + 3 < 7
    ⇒   5 < |x + 3| < 7

Then
    |x² − 9| = |x + 3| |x − 3| < 7δ ≤ 7 · ε/7 = ε     (∵ δ ≤ ε/7)

Hence  lim_{x→3} x² = 9.  ∎
```

**另解版（δ = min{2, ε/8}）**

```text
Given any ε > 0, we take
    δ = min{ 2 , ε/8 } > 0    ⇒    δ ≤ 2  and  δ ≤ ε/8

If 0 < |x − 3| < δ
    ⇒  |x − 3| < 2                  (∵ δ ≤ 2)
    ⇒  −2 < x − 3 < 2
    ⇒   4 < x + 3 < 8
    ⇒   4 < |x + 3| < 8

Then
    |x² − 9| = |x + 3| |x − 3| < 8δ ≤ 8 · ε/8 = ε     (∵ δ ≤ ε/8)

Hence  lim_{x→3} x² = 9.  ∎
```
