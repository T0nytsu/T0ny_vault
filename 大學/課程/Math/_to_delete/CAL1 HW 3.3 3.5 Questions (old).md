### ST 3.3.35
**28–35** Sketch the graph of a function that satisfies all of the given conditions.

&f(0) = f'(0) = f'(2) = f'(4) = f'(6) = 0, \\
&f'(x) > 0 \text{ if } 0 < x < 2 \text{ or } 4 < x < 6, \\
&f'(x) < 0 \text{ if } 2 < x < 4 \text{ or } x > 6, \\
&f''(x) > 0 \text{ if } 0 < x < 1 \text{ or } 3 < x < 5, \\
&f''(x) < 0 \text{ if } 1 < x < 3 \text{ or } x > 5, \quad f(-x) = f(x)
\end{aligned}
$$
