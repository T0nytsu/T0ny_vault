## 變數宣告

```kotlin
val count: Int = 2
```

**格式 :**

val `name`: `data type` = `initial value`

- `val` : value 的縮寫，用來宣告一個唯讀（read-only）的不可變量
- `var` : 可變變量
- **變數名稱** : 第一字為小寫，若包含多個單字，單字之間不能有空格，且所有其他單字的首字母都應使用大寫
- **資料型態** : 
	- `Double`
		- 小數
		- `2.0`
		- `501.0292`
	-  `Float`
		- 小數（精度較低）
		- 結尾需加 `f`
		- `5.0f`

## 函式

**格式 :**

fun `name` () :`return type` {
	`body`
	`return_statemet`
}

- 如位指定傳回類型，則傳回類型會預設為`Unit`( 同等於 Python 中的`None`或 Java 和 C 中的`Void`)
