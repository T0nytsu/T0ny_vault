可以，但要先區分兩種情況：

f(x)=\\frac{\\cos x}{x}

1\. 不定積分（Indefinite Integral）

\\int \\frac{\\cos x}{x}\\,dx

這個積分無法用一般初等函數表示，例如多項式、指數、對數、三角函數及其有限組合。

不過，它確實有定義，可以用特殊函數表示，稱為 Cosine Integral（餘弦積分）：

\\boxed{\\int\\frac{\\cos x}{x}\\,dx
=\\operatorname{Ci}(x)+C}

（在適當的定義域上。）

2\. 定積分（Definite Integral）

這就要看積分區間。

例如：

\\int_1^2\\frac{\\cos x}{x}\\,dx

因為被積函數在 連續，所以定積分存在。

但如果是：

\\int_0^1\\frac{\\cos x}{x}\\,dx

則是發散（diverges）。

原因是：

\\lim_{x\\to0^+}\\frac{\\cos x}{x}
=+\\infty

而且其積分具有類似 的對數發散性。

整理：

| 問題   | 結論           |
| ---- | ------------ |
| 不定積分 | 存在，但沒有初等函數形式 |
|      | 收斂           |
|      | 發散           |
